# 공학용 계산기 웹앱 상세 요구사항 명세서

## 1. 시스템 개요
- 프로젝트명: 공학용 계산기 웹앱
- 개발 환경: Flutter
- 배포 환경: 웹 (모바일, 태블릿, 데스크톱 지원)

## 2. 기능 요구사항

### 2.1 계산 기능
#### 2.1.1 기본 연산
- 사칙연산 지원
  - 덧셈 (+)
  - 뺄셈 (-)
  - 곱셈 (×)
  - 나눗셈 (÷)
- 괄호 처리 기능
  - 중첩 괄호 지원
  - 괄호 자동 완성

#### 2.1.2 고급 수학 함수
- 삼각함수
  - sin, cos, tan
  - arcsin, arccos, arctan
- 로그 함수
  - 자연로그 (ln)
  - 상용로그 (log)
- 지수 함수
  - 제곱 (x²)
  - 세제곱 (x³)
  - 일반 지수 (x^y)
- 기타 함수
  - 제곱근 (√)
  - 절대값 (|x|)
  - 팩토리얼 (x!)

#### 2.1.3 메모리 기능
- 메모리 저장 (M+)
- 메모리 불러오기 (MR)
- 메모리 초기화 (MC)

### 2.2 입력 방식
#### 2.2.1 키보드 입력
- 숫자 키 (0-9)
- 연산자 키
- 함수 키
- 괄호 키
- Enter 키 (계산 실행)
- Backspace 키 (한 글자 삭제)
- Delete 키 (전체 삭제)

#### 2.2.2 마우스/터치 입력
- 모든 버튼 터치 지원
- 스와이프 제스처로 계산 이력 탐색

#### 2.2.3 수식 입력 모드
- 일반 계산기 모드
  - 순차적 입력 방식
  - 실시간 계산 표시
- 공학용 수식 모드
  - 수학적 표기법 지원
  - LaTeX 스타일 수식 표시

### 2.3 결과 표시
#### 2.3.1 숫자 표시
- 소수점 4자리까지 표시
- 5자리 이상은 반올림
- 과학적 표기법 지원 (1.23e+10 형식)

#### 2.3.2 계산 이력
- 최근 10개 계산 기록 저장
- 이력 내 수식 재사용 기능
- 이력 내 결과값 재사용 기능

## 3. 비기능적 요구사항

### 3.1 사용자 인터페이스
#### 3.1.1 반응형 디자인
- 모바일 (320px ~ 480px)
- 태블릿 (481px ~ 768px)
- 데스크톱 (769px 이상)

#### 3.1.2 테마

- 시스템 테마 자동 감지

### 3.2 성능
- 단일 사용자 환경
- 실시간 계산 응답
- 계산 이력 즉시 저장

### 3.3 보안
- 사용자 인증 불필요
- 계산 결과 로컬 저장
- 세션 종료 시 이력 초기화
